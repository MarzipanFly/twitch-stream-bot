# История изменений

## 0.8.0.0 — 9 октября 2026

- Интеграция с OBS Studio через OBS WebSocket v5 с авторизацией.
- Запуск звуковых медиаисточников по настраиваемым командам Twitch-чата.
- Раздел `[sounds]` в локальном `config.ini`: название команды, источник OBS, общий кулдаун и цена.
- Списание апельсинов только после успешного запуска звука; проверка баланса и сохранение профиля.
- Каталог `!звуки` / `!sounds` с ценами.
- Уведомление об оставшемся кулдауне с ограничением частоты сообщений.
- Проверены сборка и работа команд на Twitch с OBS.

Видеоэффекты, персональные кулдауны звуков и модераторское отключение эффектов в релиз не входят.
