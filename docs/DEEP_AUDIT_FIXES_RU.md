## Ограничения, которые остаются

- **EventSub exactly once:** кольцевой буфер ограничен 2048 сообщениями, истекает через 10 минут и **не переживает перезапуск бота**. Это существенно снижает повторы в текущем процессе, но не заменяет долговременный transaction ledger с idempotency key. Не следует обещать «никогда повторно» при рестарте или необычно интенсивном чате.
- **WebSocket handover:** код и URL parser проходят локальные unit-тесты и Windows syntax-check; это не end-to-end тест на реальной сети. При неудаче перехода старое соединение сохраняется, а после его разрыва используется предыдущий восстановительный путь.
- **DPAPI память:** защита привязана к текущему Windows-пользователю; при переносе файла на другой ПК/учётную запись расшифровка может быть недоступна, оригинал не удаляется. Перед первым применением обновления сделай **локальную непубличную резервную копию** файла памяти; файл может содержать приватные сообщения. Проверяй миграцию без публикации данных.
- **Оценка ИИ:** проведён аудит данных, но новое обучение весов Ollama не выполнялось. Доказать рост интеллекта можно только сравнительным baseline/candidate-прогоном на синтетических grounded fixtures и ручной оценкой связности/галлюцинаций.
- **Persona/Memory/RAG V2:** более полная структурированная память и метаданные источников RAG остаются последующими этапами; на них нужно отдельное тестирование.
- **Производительность:** кольцевая AI-очередь и reuse HTTP-соединения не добавлены, поскольку до измерений `p50/p95` и надёжности текущей реализации не следует делать рискованный рефакторинг.
- **Autonomous Mode:** намеренно не активирован; Action Dispatcher остаётся Dry Run.

## Локальная проверка на Windows/WSL

1. Сохрани текущие локальные правки и резервную копию приватного файла памяти (`data/ai_dialog_memory.dat`, если он существует). Не коммить этот файл.
2. Проверь тесты на ветке исправлений:

```bash
git fetch origin
git switch -c fix/deep-audit-security-ai-v2 --track origin/fix/deep-audit-security-ai-v2

gcc -std=c11 -Wall -Wextra -Werror -Iinclude \
  tests/test_eventsub_dedupe.c src/eventsub_dedupe.c -o test_eventsub_dedupe
./test_eventsub_dedupe

gcc -std=c11 -Wall -Wextra -Werror -Iinclude -Ithird_party/cjson \
  tests/test_eventsub_id.c src/twitch_eventsub.c third_party/cjson/cJSON.c \
  -lm -o test_eventsub_id
./test_eventsub_id

python3 tests/check_ai_quality.py
```

3. В Qt Creator: **Run qmake → Clean → Rebuild → Run**. При наличии opt-in памяти проверь, что после запуска запись сохранилась и доступна при следующем старте. Не отправляй сырые токены или файлы памяти в отчётах.
4. Проверяй рейд и Shoutout на тестовом канале без спама. Два одинаковых EventSub ID должны давать не более одного внешнего действия в рамках окна дедупликации.
5. Проверь автоматическое восстановление WebSocket и работоспособность Twitch-подписок после reconnect.
6. Запусти существующие тесты AI Manager и Action Dispatcher. Отдельно проведи контроль приватного AI test-chat (не должен публиковаться в Twitch).

## Проверено ранее (не найдено новых подтверждённых проблем)

- Локальный Dashboard привязан к `127.0.0.1`, проверяет `Host`, `Origin` и дополнительные заголовки для управляющих запросов, использует CSP.
- В браузерной панели пользовательские строки выводятся с безопасным `textContent`, а не `innerHTML`.
- OAuth-токены уже были защищены DPAPI до этого патча.

Эти проверки не являются гарантией отсутствия других уязвимостей. Для выпуска требуется полная сборка на Windows, эксплуатационные тесты и анализ CI с конкретным коммитом.
