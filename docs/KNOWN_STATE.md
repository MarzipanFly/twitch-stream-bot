# Текущее состояние проекта

Версия: **0.6.0.0**.

## Подтверждено реальным запуском

К 03.10.2026 были подтверждены:

- Twitch OAuth и повторное использование сохранённой сессии;
- `/oauth2/validate`;
- `/helix/users`;
- `/helix/streams`;
- отправка сообщения в Twitch-чат;
- EventSub WebSocket handshake с HTTP 101;
- получение `session_welcome`;
- создание `channel.chat.message` подписки с HTTP 202;
- получение настоящей команды из Twitch-чата;
- формирование ответа командным модулем;
- отправка ответа обратно в Twitch-чат с HTTP 200.

## Версия 0.6.0.0

В обычный запуск встроена постоянная обработка Twitch-чата. Тестовый `--test-twitch-command` по-прежнему существует, но нужен только для диагностики одной команды.

Основной цикл теперь:

```text
EventSub chat
    +
stream polling
    +
OAuth validation
    +
Telegram stream notification
```

При потере EventSub-соединения бот закрывает старую сессию, ждёт несколько секунд, подключается снова и заново создаёт `channel.chat.message` подписку. Мониторинг стрима при временно недоступном чате продолжает работать.
