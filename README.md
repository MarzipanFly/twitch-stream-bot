# 🍊 ApelsinBot

**ApelsinBot** — личный помощник Twitch-стримера, который объединяет чат, музыку, OBS и инструменты для общения со зрителями.

Проект написан на **C** для **Windows**. Это развивающийся проект: бот и веб-панель постепенно получают новые возможности.

## Что умеет бот

- 💬 **Twitch-чат** — читает сообщения, отвечает на команды и обрабатывает события канала.
- 🍊 **Экономика зрителей** — апельсины, ежедневные награды, ставки, дуэли, рейтинг и случайные дропы.
- 🔊 **Звуки за апельсины** — запускает настроенные медиаисточники OBS по командам зрителей.
- 🎵 **Музыкальные заявки** — принимает ссылки на YouTube, управляет очередью и воспроизведением через OBS.
- 🎬 **Управление OBS** — переключает сцены между общением и игрой, а также помогает синхронизировать категорию Twitch с запущенной игрой.
- 🌐 **Веб-панель** — позволяет управлять настройками бота через браузер.
- 🧠 **Локальный ИИ** — отвечает на сообщения через Ollama, если эта функция настроена.
- 📣 **Уведомления и ссылки** — сообщает о начале трансляции и помогает зрителям находить Telegram и Discord.

## Проверка ответов ИИ без запуска трансляции

Открой локальную панель `http://127.0.0.1:8765`, найди карточку «ИИ-соведущий» и блок «Тестовый чат · безопасный режим». Введи пример сообщения зрителя и нажми «Сгенерировать ответ». Черновик появится в панели после обработки локальной моделью Ollama. Последние четыре обмена репликами хранятся только в RAM, чтобы можно было проверять продолжение разговора. Кнопка «Начать новый диалог» очищает временную историю.

Этот режим:
- не требует запуска трансляции или OBS;
- не отправляет сообщение в Twitch;
- не записывает тестовые реплики в долговременную память зрителей или на диск;
- требует, чтобы ИИ был включён и Ollama работала.

## Игровая база знаний и тесты ИИ

База содержит **129 справочных тем** по FC/FIFA, ETS2, Phasmophobia, Minecraft/Create, танкам, War Thunder, VALORANT, CS2, League of Legends, Rocket League и другим играм. Сведения ищутся локально и ограничены игровой темой, чтобы бот не путал разные игры.

Есть **129 примеров диалогов** для будущего дообучения и **37 тестовых сценариев**, проверяемый через приватную панель. На компьютере с Python 3:

```powershell
py -3 tests/validate_ai_data.py
py -3 tests/eval_dashboard_ai.py --limit 10 --output ai_eval_report.json
```

Это расширение базы и логики общения, **не** изменение весов локальной модели. Полная документация и ограничения описаны в [training/README.md](training/README.md).

## Эксперимент: живое общение с чатом

В режиме «Живой» ApelsinBot может отвечать на прямое обращение без команды `!бот`, например: `Апельсин, как дела?`. Функция **выключена по умолчанию**. Чтобы попробовать её, добавьте в секцию `[ai]` локального `config.ini`:

```ini
live_chat_enabled=true
live_chat_cooldown_seconds=180
```

Перезапустите бота. Автоматические ответы работают только во время трансляции, используют существующую очередь Ollama и ограничены общим кулдауном. Команды `!` и сообщения самого бота игнорируются. Для отключения верните `live_chat_enabled=false` и перезапустите бота. Это первая экспериментальная версия: пока без реакции на все сообщения подряд и без самостоятельных опросов.

## Автоматический Shoutout после рейда

Бот уже получает EventSub-событие `channel.raid`. Чтобы после входящего рейда автоматически отправлять штатную карточку Twitch с кнопкой Follow, добавьте в локальный `config.ini`:

```ini
[raids]
auto_shoutout=true
```

Для этой функции необходимы условия:

- OAuth-токен аккаунта бота должен содержать scope `moderator:manage:shoutouts`.
- Аккаунт бота должен быть модератором канала.
- Трансляция должна быть в эфире и иметь хотя бы одного зрителя — это ограничение Twitch Shoutout API.
- Twitch ограничивает Shoutout: один раз в 2 минуты для разных каналов и раз в час для одного и того же канала. Если лимит превышен, благодарность за рейд всё равно появится в чате, но карточка не отправится.

После первичной авторизации переключатель «Shoutout после рейда» доступен в главной веб-панели в разделе «Управление функциями». Его состояние сохраняется в `data/dashboard_controls.ini`, поэтому автоматическую отметку можно отключать и включать без перезапуска. Если OAuth scope ещё не был выдан, для первого включения останови бота, установи `raids=1` в `data/dashboard_controls.ini`, запусти его снова и подтверди разрешение Twitch.

После включения настройки бот проверит OAuth scope. Если сохранённый токен старый, он запросит повторную авторизацию; подтверди новый доступ в Twitch. Затем перезапусти бота. Автоматический Shoutout отправляется только на входящие рейды, не на исходящие.

## AI Manager · наблюдение за событиями

Новый модуль `src/ai_manager.c` подключён к основному циклу и в режиме **Monitor Only** получает подтверждённые рейды и подписки Twitch, прямые обращения к боту, переходы статуса трансляции и обнаруженные смены сцены OBS. Он фиксирует предложения действий и причины, но **не исполняет** их.

В локальной веб-панели появилась карточка **«AI Manager · журнал решений»** с числом событий, предложений, дубликатов и отклонений. Показаны последние восемь решений. Данные хранятся только в оперативной памяти; после перезапуска журнал очищается. Существующие реакции на Twitch и OBS работают отдельно, как прежде.

Автономные действия менеджера будут подключаться только после проверки прав, ограничений и дедупликации исполнительного слоя. Подробности в [docs/AI_MANAGER.md](docs/AI_MANAGER.md).

## Веб-панель

Когда бот запущен, локальная панель доступна по адресу:

**http://127.0.0.1:8765**

Настройки открываются по адресу:

**http://127.0.0.1:8765/settings**

Панель работает на компьютере, где запущен бот.

## Технологии

- **C** — основная логика приложения.
- **Twitch Helix API и EventSub** — взаимодействие с Twitch.
- **OBS WebSocket v5** — управление сценами и медиаисточниками.
- **Qt Creator и qmake** — сборка проекта в Windows.
- **Ollama** — локальный ИИ (необязательная функция).

## Сборка и запуск

Проект рассчитан на Windows и собирается через Qt Creator.

1. Установите подходящую среду Qt Creator с MinGW.
2. Скопируйте `config.example.ini` в `config.ini` и укажите необходимые параметры.
3. Откройте файл проекта `twitchbot.pro` в Qt Creator.
4. Выполните **Run qmake → Build → Run**.

Для работы отдельных функций могут потребоваться дополнительные настройки, например OBS WebSocket, Telegram Bot API, Ollama, `yt-dlp` и FFmpeg.

## Безопасность

- Не загружайте в GitHub файл `config.ini`, OAuth-токены, пароли или ключи API.
- Локальные данные и журналы хранятся на компьютере и не должны содержать опубликованных секретов.
- Веб-панель предназначена для локального использования.
