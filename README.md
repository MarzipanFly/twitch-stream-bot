# 🍊 ApelsinBot

Нативный Twitch-бот для Windows на C. Управляет чатом, экономикой зрителей, музыкой и OBS через локальную веб-панель.

## Возможности

- **Twitch EventSub:** сообщения чата, фолловеры, рейды, автоматическое восстановление WebSocket-соединения.
- **Экономика:** апельсины, рейтинги, награды и игры для зрителей.
- **OBS:** сцены, запись, звук, звуковые награды, автоматический режиссёр.
- **Музыка:** очередь заявок и воспроизведение через OBS.
- **Отчёты:** история эфиров, график зрителей и отметки для клипов.
- **Уведомления:** Telegram и Discord.
- **Рейды:** необязательный Twitch Shoutout с нужными OAuth-разрешениями.
- **Локальная панель:** `http://127.0.0.1:8765`, по умолчанию без доступа из сети.

## Запуск

Открой `twitchbot.pro` в Qt Creator на Windows, выполни **Run qmake → Rebuild**, затем запусти программу. Настройки задаются в собственном `config.ini` на основе `config.example.ini`. Настоящие токены, пароли и локальные данные хранить в GitHub нельзя — эти пути исключены через `.gitignore`.

При необходимости установи и настрой OBS WebSocket, `yt-dlp` и FFmpeg. Проекту **не нужны локальные модели и Ollama**.

## Удаление старого локального ИИ

Локальный ИИ (Ollama/Qwen), RAG, обучение LoRA, личность/память ИИ и AI Manager удалены из исходного кода, веб-панели и сборки. Команды `!бот` и автоматические ответы ИИ сейчас недоступны. Обычные команды Twitch и автоматический Shoutout работают независимо.

Позже можно подключить ChatGPT через отдельную интеграцию с OpenAI API, с новым разрешением на обработку сообщений зрителей. Пока API-ключ или доступ к ChatGPT нигде в проекте не используется.

**Обновление старой установки:** для очистки локальных приватных историй ИИ останови бота и отдельно удали `data/ai_dialog_memory.dat` (если он существует). Файл не передаётся в GitHub и не удаляется этим коммитом с твоего компьютера. Также можно удалить локальные модели Ollama самостоятельно, если они больше не нужны.

## Безопасность

- OAuth-токены защищены Windows DPAPI.
- Дубли EventSub подавляются до обработки событий; окно — 10 минут, кэш ограничен и сбрасывается после перезапуска.
- Адрес переподключения Twitch проверяется на допустимый хост.
- Локальная панель доступна только на loopback, управляющие запросы проходят проверки.
- Включай автоматический Shoutout только после выдачи `moderator:manage:shoutouts` и проверки роли бота.

## Проверки

В `.github/workflows/core-smoke.yml` запускаются проверки обработчиков EventSub. Для полноценной проверки изменений на Windows дополнительно собирай проект в Qt Creator и проверяй панель, Twitch и OBS.
