# 🍊 ApelsinBot

Windows-приложение на C для Twitch-чата, автоматизации OBS и управления стримом.

## Функции

- Twitch EventSub: сообщения, команды и события трансляции.
- Экономика зрителей: апельсины, рейтинги, награды и мини-игры.
- Музыкальные заявки и управление OBS.
- Локальная веб-панель `http://127.0.0.1:8765`.
- Telegram/Discord, отчёты об эфирах и настройки команд.

## Настройка

Скопируй `config.example.ini` в локальный `config.ini` и заполни настройки. Не публикуй OAuth-токены или пароли: они хранятся локально, в том числе через Windows DPAPI. Открой `twitchbot.pro` в Qt Creator и запусти `Run qmake → Rebuild`.

## Статус ИИ

Локальные Ollama/Qwen, RAG, обучение LoRA, тестовый чат и команда `!бот` **удалены**. Никакая модель не запускается и не обращается к зрителям. Отдельное подключение ChatGPT через OpenAI API возможно позже, но сейчас не реализовано.

Старый файл `data/ai_dialog_memory.dat` (если существует) не удаляется на твоём компьютере автоматически. Для удаления сохранённых разговоров сначала останови программу, затем удали этот локальный файл вручную. GitHub не получает содержимое `data/`.
